# 📦 Yalidine Delivery Dashboard

A **Business Intelligence dashboard** developed with **Python, Streamlit, SQLite, Pandas, and Plotly** to analyze delivery sales data and present business insights through interactive visualizations.

---

## 📌 Project Overview

The **Yalidine Delivery Dashboard** is a Business Intelligence application designed to analyze a dataset representing delivery sales.

The dashboard provides a visual overview of:

* Total revenue
* Total number of deliveries
* Successful delivery rate
* Customer retention rate
* Revenue by region
* Top-performing products
* Monthly revenue trends
* Delivery performance
* Customer retention
* Detailed sales data

The project uses a local **SQLite database** as its data source and **Streamlit** as the dashboard framework.

# 📂 Project Structure

```text
AssignmentBI/
│
├── app.py
├── create_database.py
├── ventes.db
├── requirements.txt
└── README.md
```

### `app.py`

The main Streamlit application.

It is responsible for:

* Connecting to the SQLite database
* Loading the sales data
* Processing the data using Pandas
* Calculating revenue
* Calculating Business Intelligence KPIs
* Displaying interactive charts
* Displaying the complete sales table
* Providing dashboard navigation

### `create_database.py`

Creates the SQLite database structure.

It creates three tables:

* `customers`
* `products`
* `sales`

This file defines the database schema but does not provide the final dataset used by the dashboard.

### `ventes.db`

The **populated SQLite database** used by the application.

The database is included in the project so that the dashboard can be run directly without requiring a separate data-generation script.

# 🗄️ Database

The project uses **SQLite** through Python's built-in `sqlite3` library.

The database contains three related tables.

---

## 👥 Customers

The `customers` table contains:

```text
id
name
phone
region
```

The database contains **40 customers** from different Algerian regions.

---

## 📦 Products

The `products` table contains:

```text
id
name
base_price_5kg
extra_price_per_kg
```

The database contains five delivery services:

1. Standard Delivery
2. Express Delivery
3. E-commerce Delivery
4. COD Delivery
5. B2B Delivery

The pricing model uses a **5 kg base weight**.

For packages above 5 kg, an additional price is applied for each extra kilogram.

---

## 🚚 Sales

The `sales` table contains:

```text
id
customer_id
product_id
weight
destination
receiver_phone
delivery_status
sale_date
```

The database contains **100 sales** covering August and September 2026.

The available delivery statuses are:

* Delivered
* Pending
* Returned
* Failed

---

# 📊 Dashboard KPIs

The dashboard displays four main KPIs.

## 💰 Total Revenue

The total revenue generated by the recorded delivery sales.

Revenue is calculated according to the project's pricing model:

```text
Revenue =
Base price for up to 5 kg
+
Additional price × extra kilograms
```

---

## 📦 Total Deliveries

The dashboard displays the total number of recorded delivery sales.

The database contains:

```text
100 deliveries
```

---

## ✅ Successful Delivery Rate

The successful delivery rate considers both:

* Delivered
* Returned

as completed delivery results.

Pending deliveries are excluded from the calculation.

Failed deliveries are considered unsuccessful.

The calculation is:

```text
Successful Delivery Rate =
Successful Deliveries
/
(Successful Deliveries + Failed Deliveries)
× 100
```

---

## 🔁 Customer Retention Rate

A customer is considered a **returning customer** if they have placed more than one order.

The retention rate is calculated as:

```text
Customer Retention Rate =
Returning Customers
/
Total Customers
× 100
```

# 📈 Dashboard Visualizations

## 📊 Revenue by Region

A bar chart displaying the total revenue associated with each customer region.

This allows the comparison of revenue performance between different regions.

---

## 🏆 Top Products

A bar chart displaying the revenue generated by each delivery service.

This makes it possible to compare the performance of the different products.

---

## 📈 Monthly Revenue Trend

An interactive line chart displaying revenue across:

* August 2026
* September 2026

This allows changes in revenue over time to be observed.

---

## 📦 Delivery Performance

A donut chart displaying:

* Successfully Delivered
* Not Successful
* Pending

This provides an overview of the delivery outcomes.

---

## 🔁 Customer Retention

A donut chart comparing:

* Returning Customers
* One-Time Customers

This provides a visual representation of customer purchasing behavior.

# 📋 Sales Data

The application includes a separate **Data** page containing the complete sales dataset.

The table displays:

* Sale date
* Sale ID
* Customer
* Customer region
* Product
* Weight
* Destination
* Delivery status
* Revenue

The data is displayed chronologically and without an additional DataFrame index.

---

# 📅 Dataset

The sales dataset covers the period:

```text
August 1, 2026 → September 30, 2026
```

There are no sales recorded on Fridays.

The database contains:

* **40 customers**
* **5 products**
* **100 sales**

The dataset was intentionally expanded from the initially planned **5 customers and 10 sales** to **40 customers and 100 sales**.

The larger dataset was used to make the Business Intelligence charts clearer and provide more meaningful visualizations and comparisons.

# ▶️ Running the Project Locally

## 1. Clone the repository

```bash
git clone https://github.com/khenkhg/AssignmentBI.git
```

Then enter the project directory:

```bash
cd AssignmentBI
```

---

## 2. Install the required packages

```bash
pip install -r requirements.txt
```

---

## 3. Run the Streamlit application

Because the repository already contains the populated `ventes.db` database, there is **no need to generate or populate the database**.

Simply run:

```bash
streamlit run app.py
```

The dashboard will then open in your browser.

---

# 🗃️ Database Creation Script

The repository also includes `create_database.py`, which contains the SQL schema used to create the database structure.

If a new empty database needs to be created, run:

```bash
python create_database.py
```

**Note:** Running this script is not necessary for normal use because the repository already contains the populated `ventes.db` database used by the dashboard.
